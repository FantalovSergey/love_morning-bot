# Описание
Бот для отправки по расписанию ежедневных сообщений
любимому человеку (и только ему) и получения от него снов,
которые записываются и могут быть им удалены.
Другие пользователи получают уведомление
об эксклюзивности использования бота.
Присутствует функционал администрирования.
Логирование в сообщениях админу и/или в лог-файлы.
Бот работает по часовому поясу Asia/Vladivostok.
Бот работает на серверах [Amvera](https://cloud.amvera.ru/).

# Сценарии взаимодействия
## Адресат
**Любое сообщение**: _**перенаправляется админу**_.

**Получить любовное сообщение сейчас**: _**бот выполняет**_
(приветствие стоит сохранять как "Доброе утро", тогда при другом времени суток
эта фраза внутри сообщения будет заменена на корректную).

**Посмотреть все сны**: _**бот присылает все сны**_.

**Записать сон** -> **текст**: _**сохранён новый сон**_.

**Записать сон** -> **отмена**: _**возврат в исходное состояние**_.

**Удалить сны**: _**бот присылает все сны с нумерацией**_ ->

-> **Индексы**: _**сны с соответствующими индексами удалены**_.

-> **Отмена**: _**возврат в исходное состояние**_.

## Админ
**Любой текст**: _**сохранён новый вариант любовного сообщения**_.

**Посмотреть все варианты сообщений**: _**бот присылает все сообщения**_.

**Посмотреть все сны**: _**бот присылает все сны**_.

**Удалить сообщения**: _**бот присылает все сообщения с нумерацией**_ ->

-> **Индексы**: _**сообщения с соответствующими индексами удалены**_.

-> **Отмена**: _**возврат в исходное состояние**_.

**Написать как бот** -> **сообщение**: _**сообщение отправляется адресату**_.

**Написать как бот** -> **отмена**: _**возврат в исходное состояние**_.

# Установка
Клонируйте репозиторий и перейдите в него в командной строке:

```
git clone https://github.com/FantalovSergey/love_morning-bot.git
```

```
cd love_morning-bot
```

Cоздайте и активируйте виртуальное окружение:

```
python3 -m venv venv
```

* Для Linux/macOS

    ```
    source venv/bin/activate
    ```

* Для Windows

    ```
    venv\Scripts\activate
    ```

Установите последнюю версию пакетного менеджера pip,
а также зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Создайте файл с переменными окружения:

```
touch .env
```

Создайте бота с помощью [BotFather](https://t.me/BotFather).

Создайте в файле .env три переменные:

```
BOT_TOKEN = токен, полученный от BotFather по окончании регистрации бота
ARINA_ID = id пользователя, для которого предназначен бот
MY_ID = id пользователя с правами администратора
```

Чтобы узнать id пользователя, перешлите любое сообщения этого пользователя
[данному боту](https://t.me/userinfobot).

Создайте папку data в корневом каталоге (диск С для Windows по умолчанию).

# Запуск
```
python love_morning.py
```

# Тестирование
При тестировании используется содержимое файла .env
(объект бота создаётся, но в текущей версии тестов используется его мок,
либо моки его методов).
Учитывайте это особенно при редактировании и дополнении тестовых функций.

Один из вариантов запуска тестов:

```
pytest --cov=love_bot
```
